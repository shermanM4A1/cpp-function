# FuncStar - 函数星标导航

扫描指定文件/文件夹，生成**函数实现**列表（自动过滤声明/原型），支持星标常用函数并一键跳转到定义行。

## 功能

1. **函数列表（仅实现）**
   - 选择单个文件或整个文件夹进行扫描（侧边栏按钮 / 资源管理器右键 / 命令面板）
   - 基于 tree-sitter 语法分析，准确区分**声明**（`int foo(int a);`）与**实现**（`int foo(int a) { ... }`），列表只显示实现
   - 按文件分组展示，支持多行签名、函数指针等复杂形式

2. **星标函数单列**
   - 悬停函数条目，点击星标按钮（或右键菜单）收藏
   - 星标函数单独列在「星标函数」视图，按文件分组，重启后保留

3. **一键跳转**
   - 点击函数列表或星标列表中的任意函数，编辑器立即打开对应文件并定位到函数所在行

## 使用

1. 点击活动栏 FuncStar 图标，打开「函数列表」视图
2. 点击视图标题栏的 **选择文件/文件夹** 按钮（或右键资源管理器中的文件/文件夹 → FuncStar: 扫描函数列表）
3. 扫描完成后，函数列表按文件分组展示
4. 悬停函数 → 点击星标按钮收藏；「星标函数」视图中点击函数即可跳转

## 支持语言

C / C++ / Java / Python / Go / JavaScript / TypeScript / Rust / C# / Ruby / PHP

## 编译（npm）
### 1. 生成 node_modules
npm install

### 2. 打包
node node_modules/@vscode/vsce/vsce package

## 安装（vsix）

```bash
code --install-extension func-star-0.0.1.vsix
```

或菜单：扩展面板 → `...` → 从 VSIX 安装…
